# 🔧 Устранение неполадок

Подробное руководство по решению проблем с VLESS Chrome Extension.

## 📋 Быстрая диагностика

Запустите скрипт проверки:

```cmd
check-installation.bat
```

Этот скрипт проверит:
- ✅ Установку Python
- ✅ Наличие всех файлов
- ✅ Регистрацию в реестре
- ✅ Extension ID в манифесте
- ✅ Состояние портов

## 🔍 Проверка логов

### Где находятся логи?

```
%LOCALAPPDATA%\VLESSChrome\native-host.log       - Логи Python host
%LOCALAPPDATA%\VLESSChrome\xray_<clientId>.log   - Логи Xray (текущий запуск)
```

### Как открыть логи?

```cmd
notepad %LOCALAPPDATA%\VLESSChrome\native-host.log
notepad %LOCALAPPDATA%\VLESSChrome\xray_<clientId>.log
```

### Что искать в логах?

**В native-host.log:**
- `ERROR` - критические ошибки
- `WARNING` - предупреждения
- `INFO` - информационные сообщения

**В xray_*.log:**
- `[Error]` - ошибки подключения
- `[Warning]` - предупреждения
- `rejected` - отклоненные соединения

## ❌ Основные проблемы

### Проблема 1: "Failed to connect to native messaging host"

**Симптомы:**
- Расширение показывает ошибку сразу при попытке подключения
- В popup отображается Extension ID и инструкция

**Причины:**
1. Native Host не установлен (не запускали `install.bat`)
2. Загружена копия расширения без поля `key` — тогда Chrome присвоит ей другой ID
3. Python не найден или в манифесте битый путь к `native-host.bat`

**Решение:**

**Шаг 1:** Запустите диагностику — она сверит ID в манифесте с ключом расширения
```cmd
check-installation.bat
```

**Шаг 2:** Если Native Host не установлен — поставьте его
```cmd
install.bat
```

**Шаг 3:** Проверьте, что ID совпадают

Откройте страницу настройки расширения (в popup при ошибке есть кнопка
«Открыть настройку») — в блоке «Диагностика» показан текущий Extension ID.
Если он не совпадает с ключом, страница покажет об этом предупреждение:
скорее всего, загружена старая копия папки `extension` без поля `key`.
Удалите её со страницы `chrome://extensions/` и загрузите папку заново.

**Шаг 4:** Если ничего не помогло — перезапустите Chrome полностью
1. Закройте все окна Chrome
2. Ctrl+Shift+Esc → Диспетчер задач
3. Завершите ВСЕ процессы "Google Chrome"
4. Запустите Chrome снова

**Шаг 4:** Проверьте реестр
```cmd
reg query "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.vlesschrome.host"
```

Должен показать путь к манифесту.

### Проблема 2: "Native host has exited"

**Симптомы:**
- Расширение подключается, но сразу отключается
- В логах: "Native host has exited"

**Причины:**
1. Python не найден
2. native_host.py имеет ошибки
3. Права доступа

**Решение:**

**Шаг 1:** Проверьте Python
```cmd
python --version
```

Должно показать версию (например, Python 3.10.x)

Если ошибка:
```cmd
# Переустановите Python с python.org
# ВАЖНО: Отметьте "Add Python to PATH"
```

**Шаг 2:** Проверьте файлы
```cmd
dir %LOCALAPPDATA%\VLESSChrome
```

Должны быть:
- native_host.py
- native-host.bat
- xray.exe
- native-host-manifest.json

**Шаг 3:** Проверьте native-host.bat
```cmd
type %LOCALAPPDATA%\VLESSChrome\native-host.bat
```

Должно содержать:
```batch
@echo off
python "%~dp0native_host.py"
```

**Шаг 4:** Тестовый запуск
```cmd
cd %LOCALAPPDATA%\VLESSChrome
python native_host.py
```

Скрипт должен запуститься (не показывать ошибок Python).

### Проблема 3: "Xray не запущен" / "xray.exe не найден"

**Симптомы:**
- Расширение сообщает "Failed to start proxy"
- В логах: "xray.exe не найден"

**Причины:**
1. xray.exe не скачан
2. Антивирус блокирует
3. Файл поврежден

**Решение:**

**Шаг 1:** Проверьте наличие xray.exe
```cmd
dir %LOCALAPPDATA%\VLESSChrome\xray.exe
```

**Шаг 2:** Если файла нет - скачайте
```cmd
cd [папка проекта]
download-xray.bat
```

Или вручную:
1. https://github.com/XTLS/Xray-core/releases
2. Скачайте `Xray-windows-64.zip`
3. Распакуйте `xray.exe`
4. Скопируйте в `%LOCALAPPDATA%\VLESSChrome\`

**Шаг 3:** Проверьте антивирус

**Windows Defender:**
1. "Безопасность Windows"
2. "Защита от вирусов и угроз"
3. "Управление настройками"
4. "Добавить исключение"
5. Добавьте папку: `%LOCALAPPDATA%\VLESSChrome\`

**Другие антивирусы:**
Добавьте исключение для `xray.exe`

**Шаг 4:** Проверьте целостность
```cmd
cd %LOCALAPPDATA%\VLESSChrome
xray.exe version
```

Должно показать версию Xray.

### Проблема 4: Расширение подключается, но интернет не работает

**Симптомы:**
- Статус "Подключено"
- Страницы не загружаются / таймаут

**Причины:**
1. Сервер недоступен
2. Неправильный VLESS URL
3. Порт заблокирован

**Решение:**

**Шаг 1:** Проверьте доступность сервера
```cmd
ping your-server.com
```

Должен быть ответ от сервера.

**Шаг 2:** Проверьте логи Xray
```cmd
notepad %LOCALAPPDATA%\VLESSChrome\xray_<clientId>.log
```

Ищите:
- `[Error]` - ошибки
- `connection refused` - сервер отклонил соединение
- `timeout` - таймаут подключения

**Шаг 3:** Проверьте VLESS URL

URL должен иметь формат:
```
vless://UUID@SERVER:PORT?параметры#название
```

Проверьте:
- UUID правильный (из 3X-UI)
- Сервер доступен
- Порт правильный (обычно 443)
- Параметры соответствуют настройкам сервера

**Шаг 4:** Попробуйте другой VLESS URL из 3X-UI

В 3X-UI может быть несколько конфигураций. Попробуйте другую.

**Шаг 5:** Проверьте настройки прокси в Chrome
```
chrome://net-internals/#proxy
```

Должно показать SOCKS5 на 127.0.0.1 и **динамический** порт (не обязательно 10808):
```
SOCKS5 127.0.0.1:<порт>
```

Порт смотрите в popup / `native-host.log` (`Xray запущен ... на порту`).

### Проблема 5: "Порт занят" / Xray не слушает порт

**Симптомы:**
- Расширение не может запустить Xray
- Ошибка "address already in use" или "Xray не слушает порт"

**Причины:**
1. Другой экземпляр Xray запущен
2. Редкий TOCTOU: порт успели занять между `get_free_port()` и стартом Xray

**Решение:**

**Шаг 1:** Посмотрите порт в логе, не гадайте 10808
```
%LOCALAPPDATA%\VLESSChrome\native-host.log
```

**Шаг 2:** Если видите чужой xray.exe — завершите
```cmd
taskkill /IM xray.exe /F
```

**Шаг 3:** Просто нажмите Подключить ещё раз — native host берёт **новый свободный** порт. Править `self.port = 10809` больше не нужно.

### Проблема 5b: WireGuard не подключается

**Симптомы:**
- Профиль WG добавлен, Xray стартует, трафик не идёт

**Проверьте:**
1. В `.conf` есть `[Interface]` с `PrivateKey` и `[Peer]` с `PublicKey` + `Endpoint`
2. Xray не ниже 1.8.6 (в проекте качается latest, сейчас 26.x)
3. `download-xray.bat` / переустановка native host после обновления
4. Лог `%LOCALAPPDATA%\VLESSChrome\xray_<clientId>.log`
5. DNS из `[Interface]` Xray **игнорирует** — это нормально

Загрузка файла: вкладка WireGuard → **Загрузить .conf**.

### Проблема 6: Медленный интернет через прокси

**Симптомы:**
- Подключение работает, но очень медленно
- Большой пинг

**Причины:**
1. Сервер далеко
2. Сервер перегружен
3. Неоптимальный транспорт

**Решение:**

**Шаг 1:** Проверьте пинг

Нажмите кнопку "Ping" в расширении.

- <100ms - отлично
- 100-300ms - нормально
- >300ms - медленно
- >1000ms - очень медленно

**Шаг 2:** Попробуйте другой транспорт

В 3X-UI создайте конфигурации:
- TCP (самый быстрый)
- WebSocket (баланс)
- gRPC (может быть медленнее)

**Шаг 3:** Выберите сервер ближе

Если возможно, используйте сервер ближе к вашему местоположению.

### Проблема 7: Расширение периодически отключается

**Симптомы:**
- Подключение работает, затем внезапно отключается
- Нужно переподключаться

**Причины:**
1. Нестабильное соединение с сервером
2. Xray падает
3. Chrome убивает фоновые процессы

**Решение:**

**Шаг 1:** Проверьте логи Xray
```cmd
notepad %LOCALAPPDATA%\VLESSChrome\xray_<clientId>.log
```

Ищите повторяющиеся ошибки перед отключением.

**Шаг 2:** Проверьте стабильность соединения

Оставьте команду запущенной:
```cmd
ping -t your-server.com
```

Смотрите, есть ли потери пакетов.

**Шаг 3:** Попробуйте другие параметры

В 3X-UI попробуйте:
- Другой транспорт (ws вместо tcp)
- С TLS (если был без)
- Другой порт

### Проблема 8: "Python не найден"

**Симптомы:**
- При запуске `install.bat`: "Python не найден"
- Команда `python --version` не работает или открывает Microsoft Store

**Решение:**

**Шаг 1:** Установите Python
1. https://www.python.org/downloads/
2. Скачайте последнюю версию (3.10+)
3. Запустите установщик
4. ⚠️ **ВАЖНО:** Отметьте "Add Python to PATH"
5. Нажмите "Install Now"

**Шаг 2:** Перезапустите командную строку

Закройте все окна cmd и откройте новое.

**Шаг 3:** Проверьте установку
```cmd
python --version
where python
```

Должно показать версию и путь к python.exe.

**Шаг 4:** Если все равно не работает

Добавьте Python в PATH вручную:
1. Win+Pause → "Дополнительные параметры системы"
2. "Переменные среды"
3. Найдите "Path" в системных переменных
4. "Изменить" → "Создать"
5. Добавьте: `C:\Users\[ВашеИмя]\AppData\Local\Programs\Python\Python310\`
6. И: `C:\Users\[ВашеИмя]\AppData\Local\Programs\Python\Python310\Scripts\`

### Проблема 9: Расширение не появляется в Chrome

**Симптомы:**
- После "Загрузить распакованное" расширение не появляется
- Ошибки на странице `chrome://extensions/`

**Причины:**
1. Выбрана неправильная папка
2. manifest.json имеет ошибки
3. Режим разработчика выключен

**Решение:**

**Шаг 1:** Проверьте режим разработчика

На `chrome://extensions/` должен быть включен переключатель "Developer mode".

**Шаг 2:** Выберите правильную папку

Нужно выбрать папку `extension`, а НЕ корневую папку проекта!

Правильно:
```
C:\...\VLESSCHROME\extension\
```

НЕправильно:
```
C:\...\VLESSCHROME\
```

**Шаг 3:** Проверьте manifest.json
```cmd
type extension\manifest.json
```

Файл должен быть валидным JSON (без ошибок синтаксиса).

**Шаг 4:** Проверьте консоль ошибок

На `chrome://extensions/` если есть ошибки - будет кнопка "Errors". Кликните на нее.

### Проверка Native Messaging

Тест подключения к Native Host:

1. Откройте консоль расширения (F12 на popup)
2. Введите:
```javascript
const port = chrome.runtime.connectNative('com.vlesschrome.host');
port.onMessage.addListener((msg) => console.log('Received:', msg));
port.onDisconnect.addListener(() => console.log('Disconnected'));
port.postMessage({action: 'status'});
```

Должно показать ответ от Native Host.

## ❓ Часто задаваемые вопросы (FAQ)

### Что такое VLESS Chrome Extension?
Расширение для Chrome, которое подключает браузер к VLESS прокси. Только Chrome использует прокси, остальные программы работают напрямую.

### Нужен ли мне свой сервер?
Да, вам нужен доступ к VLESS серверу (например, через 3X-UI панель). Расширение не предоставляет серверы.

### Где взять VLESS URL?
В панели 3X-UI: раздел "Inbounds" → ваше VLESS подключение → иконка QR-кода или "Export" → скопируйте ссылку.

### Формат VLESS URL:
```
vless://uuid@server.com:443?encryption=none&security=tls&type=tcp&host=server.com&sni=server.com#MyServer
```

### Безопасно ли это?
Код полностью открыт для проверки. Расширение не собирает данные. Используйте только свой или доверенный VLESS сервер.

### Работает ли на Mac/Linux?
Пока только Windows. Можно портировать - код открыт.

### Можно использовать в других браузерах?
Да, в любых Chromium-based: Chrome, Edge, Brave, Opera и др.

### Работает ли в режиме инкогнито?
По умолчанию нет. Включите в `chrome://extensions/` → VLESS Chrome Connector → "Разрешить в режиме инкогнито".

### Как проверить что прокси работает?
Откройте https://ifconfig.me - IP должен совпадать с IP вашего VLESS сервера.

## 🔤 Проблема с кодировкой (кракозябры)

Если при запуске `.bat` файлов видите кракозябры вместо русского текста:

### Решение 1: Измените кодировку консоли

```cmd
chcp 65001
```

Затем запустите нужный `.bat` файл.

### Решение 2: Отключите Unicode в консоли

1. Правой кнопкой на заголовок окна cmd → Свойства
2. Вкладка "Шрифт" → выберите "Consolas" или "Lucida Console"
3. OK → Перезапустите консоль
