# VLESS Chrome Extension — macOS

Поддерживаются Apple Silicon (M1–M4) и Intel. Архитектура определяется
автоматически: `arm64` → `Xray-macos-arm64-v8a`, `x86_64` → `Xray-macos-64`.

## Установка

```bash
chmod +x macos/quick-install.sh
./macos/quick-install.sh
```

Скрипт делает всё: находит рабочий Python 3, ставит `psutil`, скачивает
Xray вместе с гео-базами, снимает карантин Gatekeeper, создаёт манифест и
регистрирует хост во всех Chromium-браузерах.

Дальше — два шага вручную:

1. `chrome://extensions/` → включить «Режим разработчика»
2. «Загрузить распакованное расширение» → папка `extension`

Extension ID закреплён полем `key` в манифесте, поэтому копировать его и
перезапускать браузер не нужно. На карточке расширения должно быть:

```
lnpifiepccjepkhcohgahghhgfehikie
```

## Куда что ставится

| | Путь |
|---|---|
| Файлы хоста, xray, гео-базы, логи | `~/Library/Application Support/VLESSChrome` |
| Манифесты браузеров | `~/Library/Application Support/<Браузер>/NativeMessagingHosts` |

Это отличается от Linux, где всё лежит в `~/.config`. Путь зафиксирован
тестом `test_app_dir_on_macos_ignores_xdg` — скрипты и сам хост обязаны
смотреть в одно и то же место.

Регистрация идёт в Chrome, Chromium, Яндекс Браузер, Microsoft Edge, Brave
и Vivaldi — в те, что найдутся.

## Удаление

```bash
./macos/install/uninstall.sh
```

Останавливает работающий Xray, снимает регистрацию во всех браузерах и
спрашивает подтверждение перед удалением каталога с профилями.

## Особенности macOS

**Gatekeeper.** Скачанный `xray` помечается карантином, и неподписанный
бинарник просто не запустится — подключение падало бы без внятной причины.
Установщик снимает метку через `xattr -dr com.apple.quarantine`.

**bash 3.2.** В macOS до сих пор штатный `/bin/bash` версии 3.2, поэтому в
скриптах нет ассоциативных массивов (`declare -A`), `mapfile` и `${var,,}` —
всё это появилось в bash 4.

**Python.** `/usr/bin/python3` может быть заглушкой Command Line Tools,
которая при вызове открывает диалог установки. Установщик проверяет каждого
кандидата на реальный запуск и предпочитает Homebrew-версию. Если Python 3
не найден:

```bash
brew install python3
```

**Хранение секретов.** DPAPI — технология Windows, на macOS её нет. Вместо
неё ключ шифрования хранится в Связке ключей (`keyring`), а сами секреты
шифруются Fernet из `cryptography` — в хранилище они выглядят как
`enc:v2:...`. Нужны **оба** пакета; если любого из них нет, хост тихо
откатывается на plaintext, ничего не ломая:

```bash
python3 -m pip install --user keyring cryptography
```

Установщик ставит их вместе с `psutil` — отдельно делать ничего не нужно.

## Проверка и диагностика

Логи хоста:

```bash
tail -f ~/Library/Application\ Support/VLESSChrome/native-host.log
```

Убедиться, что хост отвечает по протоколу (это же делает установщик на
последнем шаге):

```bash
~/Library/Application\ Support/VLESSChrome/native-host.sh
```

Команда должна ждать ввод, а не завершаться с ошибкой. Выход — Ctrl+C.

## Ограничение

Скрипты написаны и проверены статически, но на живой macOS-машине не
запускались — у автора её нет. Если что-то пойдёт не так, вывод установщика
подскажет, на каком шаге: каждый шаг печатает результат отдельно.
