Настройка VLESS Connector

Последний шаг перед использованием

1
Установите Native Host

Расширение управляет Xray через небольшую программу-посредник. Запустите install.bat в корне проекта VLESSCHROME — он поставит всё сам: зависимости, Xray и регистрацию в браузере.

Путь к установщику:
Через Проводник: откройте папку проекта VLESSCHROME и запустите install.bat двойным кликом.

Через командную строку: Win+R → cmd → cd "путь\к\VLESSCHROME" → install.bat

Копировать Extension ID и перезапускать браузер не нужно — ID расширения задан заранее полем key в манифесте.
2
Проверьте связь

После установки нажмите кнопку ниже. Если Native Host отвечает — всё готово, можно закрывать эту страницу и подключаться.
