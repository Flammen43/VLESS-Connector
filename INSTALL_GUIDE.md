# 🚀 Полная инструкция по установке VLESS Chrome Extension

**Время установки: 2 минуты** (почти всё из них — загрузка Xray)

## 📋 Что нужно перед началом

- ✅ Windows 10/11
- ✅ Google Chrome (или Edge / Яндекс Браузер / Brave / Chromium)
- ✅ Python 3.7+ (обычно уже установлен)
- ✅ VLESS URL от вашего 3X-UI сервера или WireGuard `.conf`

## 🔧 Установка — 2 шага

### Шаг 1: Запустите install.bat

Откройте папку проекта в Проводнике и запустите **`install.bat`** двойным кликом.

**Что произойдёт:**
- проверится Python (и подскажет, если он не установлен);
- поставится `psutil`;
- скачается `xray.exe`, если его ещё нет (~25 МБ);
- файлы скопируются в `C:\Users\[ВашеИмя]\AppData\Local\VLESSChrome\`;
- создастся манифест Native Messaging Host с уже готовым Extension ID;
- хост зарегистрируется в Chrome, Edge, Яндекс Браузере, Brave и Chromium;
- пройдёт самопроверка со списком установленных файлов.

**Если Python не установлен:**
1. Скачайте с https://www.python.org/downloads/
2. ⚠️ **ВАЖНО:** поставьте галочку **«Add Python to PATH»**
3. Запустите `install.bat` заново

### Шаг 2: Загрузите расширение в Chrome

1. Откройте `chrome://extensions/`
2. Включите **«Режим разработчика»** (переключатель справа вверху)
3. Нажмите **«Загрузить распакованное расширение»**
4. Выберите папку **`extension`** из проекта

Всё. Появится карточка **«VLESS Chrome Connector»**, и расширение сразу готово к работе.

> **Почему больше не нужно копировать Extension ID?**
> Раньше Chrome выводил ID распакованного расширения из пути к папке, поэтому он
> был разным на каждой машине — и его приходилось вручную вписывать в манифест
> native host, а затем полностью перезапускать браузер.
> Теперь ID закреплён полем `key` в `extension/manifest.json`: он одинаков
> везде, и установщик прописывает его сам. Копирование ID и перезапуск браузера
> из инструкции убраны.

## 🧪 Проверка установки

```cmd
check-installation.bat
```

Проверяет Python, файлы, реестр и сверяет Extension ID в манифесте с ключом
расширения — то есть ловит и случай «загружена не та копия расширения».

## ✅ Готово! Теперь используйте расширение

1. Кликните на иконку расширения (фиолетовый щит в панели расширений)
2. Вставьте ваш VLESS URL в поле
3. Нажмите **"Подключить"**
4. Дождитесь зеленого статуса **"Подключено"**

### Где взять VLESS URL?

**Из 3X-UI панели:**
1. Откройте веб-панель 3X-UI
2. Перейдите в раздел **"Inbounds"**
3. Найдите ваше VLESS подключение
4. Нажмите на иконку **QR-кода** или **"Export"**
5. Скопируйте ссылку (начинается с `vless://`)

**Формат VLESS URL:**
```
vless://uuid@server.com:443?encryption=none&security=tls&type=tcp&host=server.com&sni=server.com#MyServer
```

## 🧪 Проверка подключения

После подключения откройте:
- https://ifconfig.me
- https://whoer.net

IP адрес должен совпадать с IP вашего VLESS сервера.

## 🐛 Решение проблем

### ❌ "Failed to connect to native messaging host"

**Решение:**
1. Убедитесь, что Extension ID в манифесте правильный
2. Перезапустите Chrome **полностью** (см. Шаг 6)
3. Проверьте логи: `%LOCALAPPDATA%\VLESSChrome\native-host.log`

**Расширение покажет ваш Extension ID при этой ошибке - скопируйте его и обновите манифест!**

### ❌ "Xray не запущен" или "xray.exe не найден"

**Решение:**
1. Проверьте наличие файла: `%LOCALAPPDATA%\VLESSChrome\xray.exe`
2. Если файла нет - запустите `download-xray.bat`
3. Добавьте исключение для `xray.exe` в антивирусе/Windows Defender

### ❌ Расширение не появилось в Chrome

**Решение:**
1. Убедитесь, что выбрали папку **`extension`**, а не корень проекта
2. Проверьте, что включен "Режим разработчика"
3. Проверьте консоль ошибок на странице `chrome://extensions/`

### ❌ "Неверный формат VLESS URL"

**Решение:**
1. URL должен начинаться с `vless://`
2. Проверьте, что скопировали URL полностью
3. Попробуйте скопировать заново из 3X-UI

### ❌ Python не найден

**Решение:**
1. Установите Python с https://www.python.org/downloads/
2. При установке **обязательно** отметьте "Add Python to PATH"
3. Перезапустите командную строку
4. Проверьте: `python --version`

1. Откройте `chrome://extensions/`
2. Найдите **VLESS Chrome Connector**
3. Нажмите кнопку **"Обновить"** (круговая стрелка)

1. Запустите `install.bat` — он перезапишет файлы в `%LOCALAPPDATA%\VLESSChrome`

## ⚙️ Поддерживаемые параметры VLESS

| Параметр | Описание | Значения | По умолчанию |
|----------|----------|----------|--------------|
| `encryption` | Шифрование | `none` | `none` |
| `security` | Безопасность | `tls`, `reality`, `none` | `tls` |
| `type` | Транспорт | `tcp`, `ws`, `grpc`, `h2` | `tcp` |
| `host` | Host заголовок | домен | адрес сервера |
| `path` | Путь | `/path` | `/` |
| `sni` | SNI для TLS | домен | адрес сервера |
| `alpn` | ALPN протокол | `h2`, `http/1.1` | `h2,http/1.1` |
| `fp` | TLS fingerprint | `chrome`, `firefox` | `chrome` |
| `pbk` | Reality publicKey | строка | - |
| `sid` | Reality shortId | строка | - |
